# Instalation

* Install NodeJs
* Install NPM or YARN
* Install Python
* Install project's dependencies with 

```npm install``` or ```yarn install```

## Unix

* Install make
* Install GCC

## Windows

* Install Visual Studio with C++ Development tools

# Running with NSolid

* Install NSolid

```npm install -g solid```

# Executing 

```npm run build```

# Compilar proyecto para AWS Lambda

* Install NodeJs
* Install dependencias
    * sudo apt install -y build-essential
* Compile with node-gyp configure y build
* Zip with .zip
* Upload the .zip to Lambda

## Windows

Before the previous steps, you should

* Install WSL
* Install Ubuntu
